# Optimization

This project covers optimization techniques for machine learning,
implemented with NumPy and TensorFlow.

## Tasks

| File | Description |
|------|-------------|
| `0-norm_constants.py` | Calculates the normalization (standardization) constants of a matrix |
| `1-normalize.py` | Normalizes (standardizes) a matrix |
| `2-shuffle_data.py` | Shuffles the data points in two matrices the same way |
| `3-mini_batch.py` | Creates mini-batches for mini-batch gradient descent |
| `4-moving_average.py` | Calculates the weighted moving average of a data set |
| `5-momentum.py` | Updates a variable using gradient descent with momentum |
| `7-RMSProp.py` | Updates a variable using the RMSProp optimization algorithm |
| `9-Adam.py` | Updates a variable using the Adam optimization algorithm |
| `11-learning_rate_decay.py` | Updates the learning rate using inverse time decay (numpy) |
| `12-learning_rate_decay.py` | Creates a learning rate decay operation in tensorflow |
